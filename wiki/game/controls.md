# Controls

| Action | Input |
|---|---|
| Move | `W` `A` `S` `D` |
| Look | Mouse |
| Jump | `Space` |
| Sprint | `Left Shift` |
| Sneak | `Left Ctrl` (on foot) |
| Mine / attack | Hold left click |
| Place / use | Right click |
| Hotbar | `1`–`0`, or the mouse wheel |
| Inventory | `E` |
| Chat | `T` |
| Creative mode | `C` (double-tap `Space` to fly) |
| Pause menu | `Esc` |
| Debug overlay | `X` |
| Screenshot | `F2` |
| Hide HUD | `F1` |

Holding a spell staff, `Left Ctrl` + wheel cycles its spell slot, and right click casts.
